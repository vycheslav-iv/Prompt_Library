# Техническое задание (ТЗ) — Prompt Library для ComfyUI

**Версия:** v1.1 (реализовано: проводник + каталожная модель)
**Связь:** продолжение серии Prompt Keeper (v1.0 — «последний промпт», Library — «база промптов»)

## Модель «как в реальной библиотеке»

Запись = книга на полке. Каталожная карточка: **название** (title), **аннотация** (полный текст промпта),
**полка** (folder-путь `Фото/Портреты`), **обложка** (превью), формуляр: создана / выдана (`created_at` / `last_used`),
★ «список чтения» (favorite). Поиск — по названию и тексту. Порядок полки: сначала новые / по названию А–Я /
сначала старые / недавно выданные. Вид полки — как в проводнике Windows: 🖼 Крупные (192px сетка, по умолчанию),
🎞 Средние (128px сетка), 📋 Список (96px строки); выбор запоминается в localStorage. Ничего не выдумываем —
типовые библиотечные практики.

---

# 1. Цель проекта

Разработать кастомную ноду для ComfyUI **Prompt Library** — библиотеку промптов с категориями, поиском и превью изображений, которая:

- автоматически сохраняет промпты и превью в процессе генерации (если опция включена);
- позволяет всегда вернуться к ранее созданным промптам;
- по необходимости выдаёт нужный промпт в рабочий процесс.

# 2. Зафиксированные решения (опрос 2026-09-13)

| Вопрос | Решение |
|--------|---------|
| Архитектура | **Одна универсальная нода** (и сохраняет, и выдаёт). Отдельные Saver/Browser не делаем |
| Категории | Эволюция: сначала **свободная строка + избранное**, затем (по решению пользователя) **проводник**: папки/подпапки `Фото/Портреты` с созданием/переименованием/удалением + **имена записей** |
| Превью | **Вход IMAGE проводом** от VAE Decode / SaveImage. Автоподхват последнего изображения без провода не делаем |
| Хранение | **Внешний JSON + папка превью**. Не внутри workflow/PNG (как Keeper), а общая база для всех воркфлоу |

# 3. Назначение и схема работы

Универсальная нода стоит в разрыве текстового потока и параллельно принимает изображение для превью:

```text
LLM / Keeper / ручной ввод
        │
        ▼ (STRING)
  prompt ───┐
            ▼
     Prompt Library ──► prompt_out (STRING) ──► CLIP Text Encode
            ▲
            │ (IMAGE, optional)
VAE Decode / SaveImage
```

Два режима в одном проходе `execute()`:
1. **Сквозной / сохранение** — входящий `prompt` идёт на выход как есть + сохраняется в базу (если `auto_save` и это не дубликат).
2. **Выдача** — в UI выбрана запись из библиотеки + флаг `use_selected` — на выход идёт текст выбранной записи.

# 4. Хранение данных (внешнее)

## 4.1. Расположение

```text
ComfyUI/user/prompt_library/
├── library.json
└── previews/
    └── {id}.jpg
```

- `user/` переживает обновление ноды и ComfyUI — выбрано сознательно.
- Путь резолвится от рабочей копии ComfyUI в рантайме (через `folder_paths` / `__file__`-относительно, уточнить на реализации).
- Удаление ноды базу не трёт.

## 4.2. Схема записи

`library.json` — объект `{"entries": [...], "folders": [...]}` (legacy: голый список — мигрирует автоматически).

```json
{
  "id": "a3f9c1e2",
  "title": "Дайвер в латунном шлеме",
  "prompt": "portrait, soft light...",
  "folder": "Фото/Портреты",
  "favorite": false,
  "created_at": "2026-09-13T12:00:00",
  "last_used": "2026-09-14T09:00:00",
  "preview": "previews/a3f9c1e2.jpg"
}
```

- Старые записи мигрируют: `category` → `folder`, `title` = первые 60 символов текста.
- Пустые папки хранятся в `folders` (иначе их было бы не показать в дереве).
- Удаление папки не теряет книги: записи переезжают в корень. Переименование двигает подпапки и записи (префикс).

- `id` — 10 hex от MD5(`dedup_hash + timestamp`).
- Дедупликация: хеш MD5(`prompt + \n + folder`) уже есть в базе → не сохраняем повторно (возвращаем существующий id).
- `title` — имя книги; авто: первая строка текста до 60 символов; правится в панели книги.
- Лимит: 500 последних записей, новые вставляются в начало.
- Превью: JPEG-тамбнейл, длинная сторона 256px, quality 80. Если вход `image` не подключён или пуст — запись без превью (`preview: null`).
- `category` оставлен дублем `folder` в записи — legacy-совместимость.

# 5. Входы

| Имя | Тип | Обяз. | Описание |
|-----|-----|-------|----------|
| `prompt` | STRING (multiline) | required | Окно текста (высота регулируется `prompt_height`). После выполнения показывает текст, который поступил и был записан. Ручной ввод — когда `source` не подключён |
| `folder` | STRING | required (виджет, default `""`) | Полка для автосохранения и кнопки «Сохранить»: путь `Фото/Портреты` (`/` = подпапка). Пусто = корень. (Раньше назывался `category`; старые workflow маппятся по индексу + `**kwargs`) |
| `source` | `*` (ANY) | optional | Основной вход-провод от LLM / Keeper / др. нод. Приоритетнее виджета `prompt`, конвертируется через `str()` (паттерн Prompt Keeper). Виджет при этом остаётся видимым |
| `auto_save` | BOOLEAN (default True) | required | «Сама сохраняла если включена опция». False = только выдача, без записи |
| `use_selected` | BOOLEAN (default False) | required | False = сквозной режим (входящий промпт на выход). True = на выход текст выбранной в UI записи |
| `prompt_height` | INT 40–400 (default 84) | required | Регулируемая высота окна `prompt` (JS `computeSize`, на лету через `callback`) |
| `image` | IMAGE | optional | Провод для превью. Не создаёт виджета, только коннектор |
| `selected` | STRING (hidden-виджет) | hidden/display | id выбранной записи. Пишется из JS, персистится через `extra_pnginfo` |
| `extra_pnginfo` | EXTRA_PNGINFO | hidden | Для патча workflow (как в Keeper) |
| `unique_id` | UNIQUE_ID | hidden | Для патча workflow (как в Keeper) |

Нативная кнопка `💾 Сохранить промпт` (`addWidget("button", ..., {serialize: false, canvasOnly: true})`, скил `comfyui-native-button`) стоит после `folder`: сохраняет текст из окна + папку через POST `/prompt_library/add` без запуска Queue. Совместимость с Keeper — проводом Keeper → `source`.

# 6. Выходы

| Имя | Тип | Описание |
|-----|-----|----------|
| `prompt_out` | STRING | Итоговый текст: входящий (сквозной) или текст выбранной записи (`use_selected=True`) |

Изменение текста на выходе запрещено (кроме выбора источника) — прозрачная нода, как Keeper. Второй выход `count` не делаем — счётчик виден в hint (`Книг на полке: N`).

# 7. Логика `execute()` (Python, `prompt_library_node.py`)

```
1. incoming = str(source) если source подключён, иначе виджет prompt; display = incoming
   out_text = incoming; dirty = False
   если use_selected и selected-id найден:
       out_text = запись.prompt; запись.last_used = now; dirty = True
2. fld = norm(folder)
   если auto_save и incoming непустой и hash(incoming, fld) нет в базе:
       insert {id, hash, title=auto, prompt=incoming, folder=fld, favorite=False,
               created_at=now, last_used=None, preview=thumbnail(image) или null}
       entries = entries[:500]; добавить fld + родителей в folders; dirty = True
   если dirty: write library.json (атомарно: tmp + rename)
3. если extra_pnginfo + unique_id:
       патч workflow.nodes[id].widgets_values = [display, fld, auto_save, use_selected, prompt_height, selected]
4. return {"ui": {"entries": до 200 × (id, title, head≤120, folder, favorite, created_at, last_used, has_preview),
                  "folders": [...], "selected": sel, "text": [display]},
           "result": (out_text,)}
```

Требования:
- `OUTPUT_NODE = True` (нужно для `{"ui": ...}` → `onExecuted` и для `extra_pnginfo`-патча).
- `FUNCTION = "execute"`, `CATEGORY = "My_custom_nodes/Prompts"`.
- `RETURN_TYPES = ("STRING",)`, `RETURN_NAMES = ("prompt_out",)`.
- Перезапись JSON целиком под каждый сейв допустима (база маленькая).
- Пустой `folder` = корень (`""`), без `"Без категории"`.
- `**kwargs["category"]` — совместимость со старыми workflow (виджет раньше назывался `category`).

Endpoints (`server.PromptServer`): GET `list` (`{entries, folders}`) / `entry?id` / `preview?id` (санитизация id);
POST `add` (ручное сохранение с кнопки) / `favorite` / `update` (title+prompt+folder, пересчёт hash) /
`delete` (+ файл превью) / `folder_create` / `folder_rename` (движет префикс) / `folder_delete`
(записи переезжают в корень, не теряются).

# 8. JS-интерфейс (`web/js/prompt_library.js`)

Обычными виджетами не обойтись — нужен **DOM-виджет** внутри ноды (скил `comfyui-js-extension`).

## 8.1. Компоновка (сверху вниз)

Штатные виджеты сверху: `prompt` (высота = `prompt_height` через `computeSize`, на лету через `callback` + в `onConfigure`),
`folder`, нативная кнопка `💾 Сохранить промпт` (сразу после папки), `auto_save`, `use_selected`, `prompt_height`, скрытый `selected`.
Полный входящий текст при подключённом `source` — в компактной DOM-плашке (max-height 72px, скролл, CSS-`resize`),
видимость по `onConnectionsChange`.

DOM-библиотека (`addDOMWidget`, сериализация выключена):
- тулбар: поиск (название + текст + папка, клиентский) + порядок полки (новые / А–Я / старые / недавно выданные) + вид (🖼 Крупные 192px сетка / 🎞 Средние 128px / 📋 Список 96px; выбор в localStorage);
- ряд: дерево полок (📚 Всё, ★ Избранное, 📥 Без полки + вложенные 📁 с отступом; ✏️ переименовать, 🗑 удалить с переездом книг в корень; `+ Полка` создаёт папку, в текущей — подпапку) | список книг;
- карточка: обложка, название жирным, начало текста (в списке), полка · даты, ★/🗑;
- панель книги: название, полка, полный текст, формуляр (`№ id · создана · выдана`), 📋 Копировать (clipboard + fallback), ✏️/💾 редактирование (POST `update`).

## 8.2. Хуки LiteGraph

- `onNodeCreated` — DOM-виджет, схлопывание `selected`, `computeSize` окна по `prompt_height`, кнопка `💾 Сохранить` (перестановка через `splice` после `folder`), первичная загрузка через `reload()` (GET `list`).
- `onExecuted(message)` — текст → окно `prompt` + плашка; пришедшие `entries` → полный `reload()` (дерево живёт в замыкании `onNodeCreated`); `selected` → виджет.
- `onConfigure` — `applyPromptHeight()` + `reload()` (восстановление `selected` дополняет `extra_pnginfo`-патч).
- `onConnectionsChange` — показ/скрытие плашки входящего.
- Поиск/фильтр/сортировка — чистый JS по `entries`.
- Клик по карточке → `selected = id` + автовключение `use_selected` + панель книги (GET `entry` с кэшем).
- ★/🗑 записи и ✏️/🗑 папок — прямые POST на endpoints + `reload()`; удаления через `confirm()`.

## 8.3. Стиль

Тёмная тема под ComfyUI. Дерево и список со своим скроллом (max-height ~300–336px). Превью отдаёт endpoint `GET /prompt_library/preview?id=` (файлы лежат в `user/`, вне статики ComfyUI).

# 9. Поиск, полки, порядок (правила)

- Поиск — по подстроке в названии + тексте + папке, case-insensitive, клиентский.
- Полка — путь через `/` (`Фото/Портреты`); нормализация режет пробелы и пустые сегменты; пусто = корень.
- Родительские папки дерева выводятся автоматически из путей записей.
- Избранное — boolean-флаг, ★-тоггл, фильтр `★ Избранное`.
- Порядок полки: сначала новые (default) / по названию А–Я (`localeCompare ru`) / сначала старые / недавно выданные (`last_used`).
- Переименование полки двигает префикс у подпапок и записей; удаление полки переносит её книги в корень.

# 10. Персистентность (наследие Keeper, скил `comfyui-png-persistence`)

Проблема Keeper сохраняется: workflow JSON захватывается до выполнения → виджеты пусты в PNG.

- Решение то же: патч `extra_pnginfo['workflow'].nodes[unique_id].widgets_values` на стороне Python.
- Персистим: `[display, folder, auto_save, use_selected, prompt_height, selected]` (порядок = порядок INPUT_TYPES).
- Сама база (`library.json`) в PNG не дублируется — только выбор и настройки.
- Билингва виджетов — через `locales/{lang}/nodeDefs.json` (скилы `comfyui-localization`, `comfyui-bilingual-node`), паттерн — из Keeper.

# 12. Ограничения (не делаем)

- Автоподхват последнего изображения без провода.
- Экспорт/импорт базы (TXT/JSON), облачная синхронизация.
- Пагинация/виртуализация больше 500 записей (только первые 200 в UI-пакет + поиск).
- Множественный выбор / пакетная выдача.
- Теги отдельно от папок (пока хватает полок + избранного).
- Endpoint-авторизация / многопользовательность — локальный ComfyUI, один пользователь.
