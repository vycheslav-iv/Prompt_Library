## 3. Проблемы, которые встречались (и как решали)

- **TDZ-ошибка `Cannot access 'st' before initialization`** — `st.inputTitle = ...`
  поставил до `const st = {...}` (`:623`). Правило в этом файле: присвоение только
  после `this._pl = st` (комментарий `:123`). Лечение — поле в литерал объекта
  (`pickupRow, pickupSel, inputTitle`). Смоук поймал за секунды (4 фазы упали).
- **Нужно ли менять Python?** — нет: `/add` уже брал `body.title`, `_add_entry`
  уже делал `title.strip() or _auto_title`. Проверено чтением кода, а не догадкой.
- **Нужно ли бампать `PL_JS_VERSION`?** — да: изменение видимое (новое поле),
  в отличие от §34 (там классы-якоря поведения не меняли). Смоук ждёт новый маркер.

## 4. Что важно не сломать при продолжении работы

- **Подхват живёт только потому, что нода исполняется каждый прогон.** Не убирать
  `IS_CHANGED` (см. память v1.28).
- **Классы-якоря `pl-root`/`pl-main`/`pl-scroll` удалять нельзя** (нужны §34-инструментам).
- **Вся работа с базой — под `_DB_LOCK`; рекурсия запрещена** (подхват только через
  `executed` + одноразовый токен, лимит 20, без таймеров).
- Порядок INPUT_TYPES `[mode, selected, save_folder, pickup]`; PNG-патч позиционный.
- Sizing: пол — только в `computeLayoutSize`; только boolean-стейт, никаких
  `setInterval`/`MutationObserver`; legacy `computeSize` не задавать.
- Новое DOM-поле → не забыть `INPUT_H` (+высота поля + gap) и ссылку в `st`, иначе
  смоук не дотянется.
- Тесты — только в `NodeName/tests/`; `sync.py` их не копирует.
- После каждого изменения исходника — сразу `python sync.py Prompt_Library`
  из корня бандла (без запроса), затем «перезапусти ComfyUI».
