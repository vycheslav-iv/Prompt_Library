## 3. Проблемы, которые встречались (и как решали)

- **Probe не открывал панель** (pinia-стор не находился): поиск любого стора с
  `togglePanel` + fallback на кнопку + ретрай по факту (`panelText`).
- **Смоук падал от стартового `reload()`** (затирал подставленные entries):
  состояние только через API-стабы (`/list` + `await st.reload()`).
- **Regex `/акреп/`** не ловил «Открепить» и ловил `attachClear` («прикреплённое»):
  точный `/^(Закрепить вверху папки|Открепить)$/`.
- **TDZ `st` до объявления**: ссылку класть в литерал объекта состояния.
- **«Это костыль?»** — закрыто честно: два доказательства отсутствия
  писателя (скан + ловушка) вместо рассуждений; итог в §37.7–37.8.
- **Chrome ругался на вставку в консоль**: сказать пользователю набрать
  `allow pasting` + Enter.

## 4. Что важно не сломать при продолжении работы

- **Закреп ТОЛЬКО в папке** (решение пользователя): кнопка и pinned-first лишь
  при `selFolder` без `__`.
- **Подхват живёт исполнением каждый прогон**: не убирать `IS_CHANGED` (v1.28).
- **Классы-якоря `pl-root`/`pl-main`/`pl-scroll` не удалять** (§34-инструменты).
- **`st.unstickWidth` не удалять**: fossil-значения некому создать, но старые
  экземпляры он лечит; удаление вернёт риск вечного зажима (§37).
- **База — под `_DB_LOCK`; рекурсия запрещена** (подхват через `executed`+токен).
- Порядок INPUT_TYPES `[mode, selected, save_folder, pickup]`; PNG-патч позиционный.
- Sizing: пол — только в `computeLayoutSize`; boolean-стейт; без таймеров и
  наблюдателей; legacy `computeSize` не задавать.
- Новое поле записи → `setdefault` в `_load_db` + `_add_entry` + `plMap` + тесты.
- Тесты — только в `NodeName/tests/`; `sync.py` их не копирует.
- После изменения исходника — сразу `python sync.py Prompt_Library` из корня
  бандла, затем «перезапусти ComfyUI».
