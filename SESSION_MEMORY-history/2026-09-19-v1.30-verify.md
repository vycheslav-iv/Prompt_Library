## 3. Проблемы, которые встречались (и как решали)

- **Смоук: стартовый `reload()` затирал подставленные `st.entries`** — фаза ставила
  записи напрямую, а висящий `reload()` (async) сбрасывал их в `[]` при первом
  `await` (0 карточек). Лечение — записи через стаб `/list` + `await st.reload()`,
  как в живую (заодно проверяется `plMap`). Урок: в смоуке состояние только через
  API-стабы, никаких прямых подмен перед `await`.
- **Смоук: regex `/акреп/` не ловил «Открепить»** (там нет «а» после «О») и ловил
  лишнее (`attachClear.title` «Убрать прикреплённое превью»). Лечение — точный
  `/^(Закрепить вверху папки|Открепить)$/`. Урок: regex по title — только точные.
- **Тест писал мусор** — первая версия legacy-проверки содержала мёртвую строку
  с `if False`; переписано чисто (`pop` + `_save_db` + `_load_db`).

## 4. Что важно не сломать при продолжении работы

- **Закреп действует ТОЛЬКО в папке** (решение пользователя): кнопка 📌 рисуется
  только при `selFolder` без префикса `__`, pinned-first — там же. Во «Всё» /
  «Избранном» / «Без категории» — обычный порядок, кнопок нет.
- **Подхват живёт только потому, что нода исполняется каждый прогон.** Не убирать
  `IS_CHANGED` (см. память v1.28).
- **Классы-якоря `pl-root`/`pl-main`/`pl-scroll` удалять нельзя** (нужны §34-инструментам).
- **Вся работа с базой — под `_DB_LOCK`; рекурсия запрещена** (подхват только через
  `executed` + одноразовый токен, лимит 20, без таймеров). Новый мутирующий роут:
  `@_locked` + `_save_db` + `_broadcast_refresh()`.
- Порядок INPUT_TYPES `[mode, selected, save_folder, pickup]`; PNG-патч позиционный.
- Sizing: пол — только в `computeLayoutSize`; только boolean-стейт, никаких
  `setInterval`/`MutationObserver`; legacy `computeSize` не задавать.
- Новое поле записи → `setdefault` в `_load_db` (без перезаписи) + явное в
  `_add_entry` + `plMap` + тесты.
- Тесты — только в `NodeName/tests/`; `sync.py` их не копирует.
- После каждого изменения исходника — сразу `python sync.py Prompt_Library`
  из корня бандла (без запроса), затем «перезапусти ComfyUI».
