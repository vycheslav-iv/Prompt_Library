## 1. Что делали в этой сессии (кратко)

Разбирали живую жалобу по воркфлоу `Krea2_MY2`: нода `PromptLibrary #1925` (режим
«Запись», `pickup = 1622` «Итоговый Promt») сохраняла промпт **через раз** —
«то добавляет, то не добавляет», зависимости найти не удавалось. Причина найдена и
доказана по исходникам: **нода с подхватом не имеет проводов → ComfyUI кэширует её
по виджетам → `execute()` со второго одинакового Queue не вызывается**, а для
закэшированной ноды ядро пере-рассылает `executed` со **старым, уже потраченным**
токеном → `400 unknown token` → тишина. Сопоставление PNG-прогонов с базой: 8 из 48.
Дедупликация ни при чём. Лечение — `IS_CHANGED` (§33), плюс видимость пропусков.

## 3. Проблемы, которые встречались (и как решали)

- **«Подхват то пишет, то нет»** — кэш ComfyUI по виджетам (см. §1). Ключевые
  места ядра: `execution.py:83` (подхватывает `IS_CHANGED`), `caching.py:117`
  (подпись `[class_type, is_changed]`), `asset_enrichment.py: emit_cached_output`
  (пере-рассылка `cached.ui`). `[NaN] == [NaN]` → `False`, `hash(nan)` разный →
  ключ не совпадает → нода всегда исполняется.
- **Цена решения (осознанная):** включённый подхват снимает кэш со ВСЕЙ ветки за
  нодой. Для LLM-воркфлоу это плюс (текст всегда свежий), для фиксированного сида —
  «кэш не работает». Записано в §33.3 и README.
- Ранее в проекте (остаётся актуальным): гонка read-modify-write → `_DB_LOCK`
  (`os.replace` файл не портит, пропадало чужое изменение); mute = `mode 2`,
  bypass = `4` (проверять по `app.ts`, не по догадке); слово из середины промпта →
  роут `/search` (в `/list` только `head` ≤120); `this.id` в `onNodeCreated` = `-1`;
  subgraph-id `"5:12"`; видео-обложка → PyAV; замена обложки → `st.previewStamp`.

## 4. Что важно не сломать при продолжении работы

- **Подхват живёт только потому, что нода исполняется каждый прогон.** Не убирать
  `IS_CHANGED` и не «оптимизировать» его: без NaN записи снова начнут теряться
  молча. Если однажды появится способ получать токен без `execute()` (например,
  `on_prompt_handler`) — сначала живая проверка, потом замена.
- **Вся работа с базой — под `_DB_LOCK`.** Новый роут: `@_locked` (POST) или
  `@_locked_get` (GET); внутри — НИКАКИХ `await` (тело читает декоратор).
- **Рекурсия запрещена**: значение, рождающееся в прогоне (обложка, финальный
  текст), забирается из событий `executed` + одноразовый токен, а не проводом назад.
- Всё, что нужно ПОСЛЕ прогона, живёт в токене (`_PICKUP`, лимит 20, без таймеров).
- Порядок INPUT_TYPES `[mode, selected, save_folder, pickup]`; PNG-патч позиционный.
- Sizing: пол — только в `computeLayoutSize`; читать только boolean-стейт, никогда
  размеры DOM; никаких `setInterval`/`MutationObserver`; legacy `computeSize` не задавать.
- Broadcast: `send_sync` + `app.api.addEventListener`; из новых роутов не забывать
  `_broadcast_refresh()`.
- Подхват: дубль НЕ тостить (событие летит на каждый Queue) — только `hintSticky`;
  пропуски (нет токена / отказ) — обязательно показывать, а не молчать.
- `media` описывает ТЕКУЩУЮ обложку; id, уходящий в имя файла, обязан проходить
  `^[a-zA-Z0-9]+$`.
- Правка карточки: вход ✏️ → выход 💾 ИЛИ ✖; после замены обложки НЕ звать
  `st.fillDetail` (сотрёт несохранённый текст).
- Тесты — только в `NodeName/tests/`; `sync.py` их не копирует.
