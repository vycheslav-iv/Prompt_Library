# Prompt Library

Библиотека промптов для ComfyUI как настоящая библиотека: книги (название + текст + обложка-превью) по категориям (дерево, подкатегории), поиск по названию и тексту, порядок категории, ★ избранное, дата выдачи. Автосохранение с превью и выдача нужного промпта в рабочий процесс.

Продолжение серии Prompt Keeper (тот хранит последний промпт, этот — всю базу).

## Схема

```text
LLM / Keeper → source ──┐
                        ▼
                 [Prompt Library] → prompt_out → CLIP Encode
```
Ручной ввод — в окно; провод — в подписанный вход `source` («Промт (вход)»).

**Достаточно ОДНОЙ ноды** (с v1.24): обложку она берёт не проводом, а из
результатов прогона — после Queue клиент присылает серверный список созданных
файлов, и нужный становится превью записи. Поэтому кольца в графе больше нет,
а «сохранять» и «выдавать» — просто режим ноды.

> Провод `image` остался как опция: он нужен, когда картинка НЕ из этого прогона
> (загружена с диска, из другого воркфлоу). Вместе с выходом в CLIP он снова даёт
> кольцо — нода подсветится и предупредит, Queue бы упал.

## Режимы (переключатель `Режим`)

| Режим | Выход | Что с базой |
|---|---|---|
| **📥 Запись** | пусто — нода только сохраняет | сохраняет входящий промпт |
| **📤 Выдача** | текст выбранной записи | ничего не сохраняет |
| **📤📥 Выдача + запись** | как в выдаче | выдаёт и сохраняет в один прогон |

## Подхват финального текста (с v1.25)

Если карточка уходит из ноды в LLM-цепочку, провод назад с результатом даёт
**кольцо** в графе (ComfyUI исполняет только ацикличный граф) — раньше из-за
этого и требовались две ноды. Теперь провод назад не нужен:

```text
[Prompt Library] 📤 Выдача ──▶ LLM-цепочка ──▶ финальный текст ──▶ CLIP
        ▲                                                             │
        └── 📎 Текст в базу: <узел с финальным текстом> ◀──────────────┘
            (не провод — подхват ПОСЛЕ Queue)
```

- поле **📎 Текст в базу** (первая строка ноды) — выбрать узел, чей текст сохранить;
- после Queue нода берёт текст этого узла из событий прогона и сохраняет как новую
  запись вместе с обложкой этого же прогона;
- пока подхват включён, входящий текст (`source`) не сохраняется — об этом нода
  говорит подсказкой внизу (вернуть «как раньше» — выбрать «— из входа (провод) —»);
- повторная генерация того же текста не плодит записи — нода напишет, где лежит оригинал.
- **Важно (с v1.28):** пока подхват включён, нода исполняется в **каждом** Queue (без этого ComfyUI кэшировал её по виджетам, `execute()` не вызывался и запись терялась — «то добавляет, то не добавляет»). Значит, и вся ветка за источником исполняется каждый прогон, а не берётся из кэша. Если подхват не нужен — снимите выбор, и нода снова начнёт кэшироваться.
- Пропущенный подхват больше не молчит: если токена нет или сервер отказал, причина появляется в нижней строке ноды и в консоли (F12).

- Дедупликация по тексту — в любой категории: тот же промпт в другой папке второй раз не сохраняется, а показывается, где лежит оригинал.
- В режиме выдачи клик по карточке только выбирает запись (режим вручную не переключается) и фиксируется дата выдачи.
- Если в старом графе «Запись» стояла в разрыв перед CLIP (выход подключён проводом), нода отдаёт текст сквозь, как раньше, и говорит об этом подсказкой.

## Превью: фото, видео и замена (с v1.26)

- Обложка ставится сама из этого же прогона — фото или **видео** (`mp4`, `webm`, `mkv`, `mov`, …): у видео берётся первый кадр.
- В ручном вводе кнопка `📷 Прикрепить превью` принимает **и картинку, и видео** (кадр видео снимает браузер).
- Обложку существующей записи можно **заменить**: откройте книгу в панели справа, нажмите `✏️ Редактировать` → `🖼 Заменить превью` (или `🎬`, если сейчас стоит видео) и выберите файл. Кнопка спрашивает подтверждение — прежняя обложка перезаписывается и вернуть её нельзя.
- Метка типа (📷 фото / 🎬 видео) следует за обложкой — по ней работает фильтр «Тип» в тулбаре.
- Хранится одна картинка PNG 512px с вшитым воркфлоу (как и раньше) — файл видео в базе не копируется.

## Сохранение

- Автоматически при Queue (режимы 📥 Запись и 📤📥 Выдача + запись, дедупликация по тексту — любая категория). Обложка прикрепляется сама — картинкой **или первым кадром видео** из этого же прогона.
- Подхватом (📎 Текст в базу, с v1.25) — текст выбранного узла после прогона: одна нода и на «взять карточку», и на «сохранить результат LLM».
- Кнопка **💾 Сохранить промпт** — текст из окна в открытую в дереве категорию, без запуска Queue
  (можно приложить превью с диска — `📷 Прикрепить превью`, даунскейл до 512px в браузере).
- Обе ноды Library в графе (и вкладки) обновляют список сами: любое изменение
  (сохранение, удаление карточек/папок, ★, переименование, перетаскивание) — ноды
  одного графа синхронны сразу, а между вкладками сигнал идёт через WebSocket
  `prompt_library/refresh` → перечитывается база (`GET /prompt_library/list`).
- Куда сохраняет: на какой категории стоит дерево, туда и пишет («Всё» = корень). Отдельного поля нет.

## UI ноды

- Провод от LLM/Keeper — во вход `source`; окно показывает входящий текст после выполнения.
- Поиск по названию/тексту/категории — **по всему тексту промпта**, а не только по его началу (с v1.27: совпадение в середине длинной книги ищет сервер и приходит через мгновение после локальных) + порядок категории + вид как в проводнике (🖼 Крупные / 🎞 Средние / 📋 Список, запоминается) + фильтр типа (Всё / 📷 Фото / 🎬 Видео — метка ставится сама: по типу провода превью или по файлу прогона).
- Кнопка `➕ Добавить промпт` — ручной ввод в текущую категорию, без запуска Queue
  (поле «Название» — необязательно: пусто = название из начала промпта).
- Дерево категорий: 📚 Всё, ★ Избранное, 📥 Без категории + категории (создать `+ Категория`, ✏️ переименовать, 🗑 удалить — книги переезжают в корень, не теряются; 🔄 перетаскивание мышью; **одна умная кнопка «📤 Экспорт»** рядом с `+ Категория`: при метках → отмеченное, без меток → текущая категория/вся база); без 📤 на каждой строке (было — шум, переработано).
- Клик по книге = выбрать + панель: название, категория, полный текст, формуляр, 📋 Копировать, ✏️/💾 правка, 💾 **Экспортировать** (v1.33: запись на диск — системный выбор папки, Chrome/Edge; с обложкой — подпапка `<название>/` с `.md` и превью, без обложки — только `.md` в выбранную папку), 📥 Воркфлоу. В режиме правки появляются **✖ Отмена** (выйти без сохранения; спросит, если правки есть) и **🖼 Заменить превью** (тоже с подтверждением). Кнопки `💾` не боятся двойного клика — второй клик игнорируется, пока идёт запись.
- Массовый экспорт (v1.34): **одна умная кнопка «📤 Экспорт»** в шапке проводника (рядом с «+ Категория»): при активных метках (Ctrl/Shift) экспортирует отмеченные записи и категории, без меток — текущую выбранную категорию (и «Всё»/«Избранное»/«Без категории» — вся база). Пишет на диск зеркало иерархии: папка категории → `.md` + обложка рядом, подкатегории — вложенными папками. Идёт с резиновым прогресс-баром в нижней строке (скрывая подсказку до/после экспорта). Chrome/Edge (File System Access API). Отдельных 📤 на строках дерева и в bulk-баре НЕТ (переработано).
- В списке узлов `📎 Текст в базу` не показываются узлы в режимах **mute и bypass** — они всё равно не исполнились бы (с v1.27).
- Ctrl/Shift+клик по карточкам и категориям — мультивыделение и массовое удаление (кнопки массового экспорта/удаления в нижней строке НЕТ — поведение определяется умной кнопкой в шапке проводника: метки → отмеченное, без меток → категория/вся база, §39; Esc/пустое место — снять выделение).
- Кнопки книги: 📌 Закреп (только в папке — книга висит вверху папки), ★ Избранное, ✏️ Переименовать, 🗑 Удалить.
- Карточка несёт воркфлоу: тяни её на канвас (или 📥 в панели) — откроется сохранённый граф, как из PNG. Сам файл превью тоже с workflow внутри — открывается и из проводника.

## Хранение

`ComfyUI/user/prompt_library/library.json` (`{entries, folders}`) + `previews/{id}.png`
(PNG 512px со встроенным чанком `workflow`, legacy `{id}.jpg` мигрирует сам) — общая
база для всех воркфлоу, переживает обновления. Старый формат (список, `category`) и
битые записи мигрируют автоматически.

Префикс `__` в именах категорий зарезервирован под служебные ветки дерева
(`__all` — «Всё», `__fav` — «Избранное», `__root` — «Без категории»), поэтому такие
имена не создаются.

## Установка

Скопировать папку `Prompt_Library` в `ComfyUI/custom_nodes/` и перезапустить ComfyUI.
