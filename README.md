# Prompt Library

Библиотека промптов для ComfyUI как настоящая библиотека: книги (название + текст + обложка-превью) по категориям (дерево, подкатегории), поиск по названию и тексту, порядок категории, ★ избранное, дата выдачи. Автосохранение с превью и выдача нужного промпта в рабочий процесс.

Продолжение серии Prompt Keeper (тот хранит последний промпт, этот — всю базу).

## Схема

```text
LLM / Keeper → source ──┐
                        ▼
                 [Prompt Library] → prompt_out → CLIP Encode
```
Ручной ввод — в окно; провод — в подписанный вход `source` («Промт (вход)»).

**Достаточно ОДНОЙ ноды** (с v1.24): обложку она берёт не проводом, а из
результатов прогона — после Queue клиент присылает серверный список созданных
файлов, и нужный становится превью записи. Поэтому кольца в графе больше нет,
а «сохранять» и «выдавать» — просто режим ноды.

> Провод `image` остался как опция: он нужен, когда картинка НЕ из этого прогона
> (загружена с диска, из другого воркфлоу). Вместе с выходом в CLIP он снова даёт
> кольцо — нода подсветится и предупредит, Queue бы упал.

## Режимы (переключатель `Режим`)

| Режим | Выход | Что с базой |
|---|---|---|
| **📥 Запись** | пусто — нода только сохраняет | сохраняет входящий промпт |
| **📤 Выдача** | текст выбранной записи | ничего не сохраняет |
| **📤📥 Выдача + запись** | как в выдаче | выдаёт и сохраняет в один прогон |

## Подхват финального текста (с v1.25)

Если карточка уходит из ноды в LLM-цепочку, провод назад с результатом даёт
**кольцо** в графе (ComfyUI исполняет только ацикличный граф) — раньше из-за
этого и требовались две ноды. Теперь провод назад не нужен:

```text
[Prompt Library] 📤 Выдача ──▶ LLM-цепочка ──▶ финальный текст ──▶ CLIP
        ▲                                                             │
        └── 📎 Текст в базу: <узел с финальным текстом> ◀──────────────┘
            (не провод — подхват ПОСЛЕ Queue)
```

- поле **📎 Текст в базу** (первая строка ноды) — выбрать узел, чей текст сохранить;
- после Queue нода берёт текст этого узла из событий прогона и сохраняет как новую
  запись вместе с обложкой этого же прогона;
- пока подхват включён, входящий текст (`source`) не сохраняется — об этом нода
  говорит подсказкой внизу (вернуть «как раньше» — выбрать «— из входа (провод) —»);
- повторная генерация того же текста не плодит записи — нода напишет, где лежит оригинал.
- **Важно (с v1.28):** пока подхват включён, нода исполняется в **каждом** Queue (без этого ComfyUI кэшировал её по виджетам, `execute()` не вызывался и запись терялась — «то добавляет, то не добавляет»). Значит, и вся ветка за источником исполняется каждый прогон, а не берётся из кэша. Если подхват не нужен — снимите выбор, и нода снова начнёт кэшироваться.
- Пропущенный подхват больше не молчит: если токена нет или сервер отказал, причина появляется в нижней строке ноды и в консоли (F12).

- Дедупликация по тексту — в любой категории: тот же промпт в другой папке второй раз не сохраняется, а показывается, где лежит оригинал.
- В режиме выдачи клик по карточке только выбирает запись (режим вручную не переключается) и фиксируется дата выдачи.
- Если в старом графе «Запись» стояла в разрыв перед CLIP (выход подключён проводом), нода отдаёт текст сквозь, как раньше, и говорит об этом подсказкой.

## Превью: фото, видео и замена (с v1.26)

- Обложка ставится сама из этого же прогона — фото или **видео** (`mp4`, `webm`, `mkv`, `mov`, …): у видео берётся первый кадр.
- В ручном вводе кнопка `📷 Прикрепить превью` принимает **и картинку, и видео** (кадр видео снимает браузер).
- Обложку существующей записи можно **заменить**: откройте книгу в панели справа, нажмите `✏️ Редактировать` → `🖼 Заменить превью` (или `🎬`, если сейчас стоит видео) и выберите файл. Кнопка спрашивает подтверждение — прежняя обложка перезаписывается и вернуть её нельзя.
- Метка типа (📷 фото / 🎬 видео) следует за обложкой — по ней работает фильтр «Тип» в тулбаре.
- Хранится одна картинка PNG 512px с вшитым воркфлоу (как и раньше) — файл видео в базе не копируется.

## Несколько выходов: категория «🔌 Выходы» (с v1.45)

Одна нода может отдавать несколько промптов по разным проводам (роли для LLM:
`system` / `prompt` / `style` / `negative` и т.п.).

- Штатные выходы: **«путь категории»** (первый) и **«промпт 1 (основной)»** (основной текст, вторым) — порядок такой же, как идут значения в ноде.
- Дополнительные выходы **не висят на ноде зря**: выход появляется только тогда,
  когда к нему что-то привязано (всего до 11 промптов).
- **Как привязать**: перетащите карточку или категорию в категорию **«🔌 Выходы»**
  в проводнике — или выделите её и нажмите кнопку **«🔌 Подключить выход»**.
- **Номер выхода = место в списке**: перетаскивая строки в «Выходах» вверх/вниз,
  вы решаете, что уходит в конкретный провод (сами провода остаются на месте).
  На карточках и категориях видно, к какому выходу они подключены (`🔌3`).
- **Выбранная карточка держится**, пока вы не выберете другую: переключение
  категорий для просмотра больше не сбрасывает выбор и не гасит основной текст
  на выходе. Панель промпта при этом остаётся открытой.
- **Категория-вывод** отдаёт текст не всей папки, а выбранной внутри неё карточки
  (клик по карточке в «Выходах»).
- **✖** на строке отвязывает выход: провод отключается, сокет исчезает, номера
  остальных сдвигаются вместе со своими привязками.
- Смена привязки = перепрогон ноды при следующем Queue (привязки входят в ключ кэша).
- Запись, удалённая из базы, отдаёт по проводу «(запись удалена)».

## Галерея в HTML (с v1.46)

Выгрузка наружу не только `.md`-файлами, но и **одной html-страницей-галереей**:
карточки с обложками, полным промптом и **параметрами генерации** (модель, VAE,
LoRA, семплер, шаги, CFG, denoise, сид, разрешение).

- **«🌐 Экспорт в HTML»** — со v1.48 живёт в строке «Библиотека:» (под «➕ Добавить промпт», вместе с «📤 Экспорт»); умная кнопка, как у экспорта: при активных метках (Ctrl/Shift) сохраняет отмеченные записи и категории, без меток — текущую категорию (и «Всё»/«Избранное»/«Без категории» — всю базу). Рядом — пока выключенная «📥 Импорт» (функционал импорта ещё не сделан, место под него уже есть).
- **«🌐 В HTML»** в панели книги — галерея одной записи.
- Что получается на диске: `prompt_library.html` + обложки **файлами рядом** (относительные ссылки, не base64) — для категории внутри одноимённой папки, вложенные категории — подпапками.
- В галерее: шапка со счётом и датой, карточки (обложка открывается в новой вкладке, «Промпт» и «Параметры генерации» — раскрывающиеся блоки), кнопка «📋 Копировать промпт» — работает и просто из файла.
- **Промпты разложены по категориям** (v1.47): каждый раздел начинается со своего пути («📁 Фото/Портреты») и счётчика, вложенные — с отступом. Если выбрана одна категория — заголовков нет, лишнего шума не появляется.
- **Параметры генерации** — только то, чем реально генерили: модель, VAE, LoRA (с силами), семплер, шаги, CFG, denoise, сид, разрешение. Работает и для нестандартных графов (с v1.47–v1.50): модель ищется по активной цепочке до семплера — даже если она подключена через **сабграф** и кастомный лоадер, а LoRA — из слотов `Power Lora Loader (rgthree)` (только включённые). **Переключатели разрешаются** (`ComfySwitchNode`, `DeggSwitch`): если в графе свитч между моделями, в галерею попадёт выбранная ветка и её LoRA, а не все сразу; внутренние лоадеры читаются с учётом значений, поднятых в сабграф. Апскейлеры (SeedVR2 и т.п.) в «Модель» не лезут. Если значение переключателя понять нельзя — нода честно напишет «активную ветку определить не удалось» и покажет все ветки. У ручных записей без прогона — «нет данных прогона».
- **Врать нечем** (v1.51): если переключатель стоит на ветке БЕЗ LoRA, LoRA и не показывается — фолбэк «по всему графу» больше не подмешивает выключенную ветку сабграфа. Модель и шаги при этом остаются верными, а плоские графы без проводов читаются как раньше.
- **Провод важнее виджета** (v1.50): если шаги/CFG/denoise/сид/размер латента подключены проводом (типично, когда шаги задаются свитчем в сабграфе), берётся значение ИСТОЧНИКА, а не устаревшее число в виджете сэмплера. Понимаются сабграфы, свитчи и узлы-константы; разрешение умеет читать из `Degg Res Set` (preset 1 — расчёт из аспекта/МП, 2–4 — ручные w/h). Непонятный источник → честный фолбэк на виджет. Сигма-сэмплеры (`SamplerCustomAdvanced` + `ManualSigmas`, видео LTX) шагами не считаются — эти поля останутся пустыми.
- `.md`-файлы галерея не заменяет: «📤 Экспорт» и «💾 Экспортировать» работают как раньше.
- Chrome/Edge — как у прочих экспортов на диск.

## Сохранение

- Автоматически при Queue (режимы 📥 Запись и 📤📥 Выдача + запись, дедупликация по тексту — любая категория). Обложка прикрепляется сама — картинкой **или первым кадром видео** из этого же прогона.
- Подхватом (📎 Текст в базу, с v1.25) — текст выбранного узла после прогона: одна нода и на «взять карточку», и на «сохранить результат LLM».
- Кнопка **💾 Сохранить промпт** — текст из окна в открытую в дереве категорию, без запуска Queue
  (можно приложить превью с диска — `📷 Прикрепить превью`, даунскейл до 512px в браузере).
- Обе ноды Library в графе (и вкладки) обновляют список сами: любое изменение
  (сохранение, удаление карточек/папок, ★, переименование, перетаскивание) — ноды
  одного графа синхронны сразу, а между вкладками сигнал идёт через WebSocket
  `prompt_library/refresh` → перечитывается база (`GET /prompt_library/list`).
- Куда сохраняет: на какой категории стоит дерево, туда и пишет («Всё» = корень). Отдельного поля нет.

## UI ноды

- Провод от LLM/Keeper — во вход `source`; окно показывает входящий текст после выполнения.
- Поиск по названию/тексту/категории — **по всему тексту промпта**, а не только по его началу (с v1.27: совпадение в середине длинной книги ищет сервер и приходит через мгновение после локальных) + порядок категории + вид как в проводнике (🖼 Крупные / 🎞 Средние / 📋 Список, запоминается) + фильтр типа (Всё / 📷 Фото / 🎬 Видео — метка ставится сама: по типу провода превью или по файлу прогона).
- Кнопка `➕ Добавить промпт` — ручной ввод в текущую категорию, без запуска Queue
  (поле «Название» — необязательно: пусто = название из начала промпта).
- Дерево категорий: 📚 Всё, ★ Избранное, 🔌 Выходы (привязки доп. выходов), 📄 Без категории + категории (создать `+ Категория`, ✏️ переименовать, 🗑 удалить — книги переезжают в корень, не теряются; 🔄 перетаскивание мышью). В шапке проводника с v1.48 — только `+ Категория`: кнопки экспорта переехали в отдельную строку (см. ниже), без 📤 на каждой строке (было — шум, переработано).
- **«📥 Импорт»** (v1.56–v1.57) — вернуть библиотеку из файлов: нажмите, выберите источник, дальше идёт прогресс (тот же бар, что у экспорта) и отчёт в нижней строке. **Четыре источника**: 📁 папка с `.md` и обложками (то, что выгружает «📤 Экспорт» — категории восстанавливаются, обложки подхватываются, параметры генерации возвращаются из картинки); 🖼 **PNG из ComfyUI** (промпт читается из графа внутри файла, обложкой становится сам PNG — «Параметры генерации» вернутся из него же); 🌐 **HTML-галерея** (сгенерированный экспортом `prompt_library.html` — карточки, текст, ★, тип, обложки); 📝 **текстовый файл** (`.txt`/`.md` — разбить на записи Абзацами / Строками / целым файлом). **Куда**: туда, где выбрано в проводнике — «📚 Всё» восстанавливает структуру 1:1, реальная папка кладёт содержимое внутрь себя, «📄 Без категории» — плоско в корень (или со структурой, если выбрать так). Что уже есть в базе — **не импортируется**: в конце скажут, сколько дубликатов пропущено и где они лежат.
- Строка **«Библиотека:»** (v1.48) — под «➕ Добавить промпт»: `📤 Экспорт` (файлы `.md` + обложки), `🌐 Экспорт в HTML` (галерея) и выключенная `📥 Импорт` — место под будущий импорт. С v1.52–v1.53 здесь же **справа** появляется ПАРА массовых действий — `🗑 Удалить` и `✖ снять метки` рядом: слева делящие действия, справа действия над метками. Счётчик помеченного остался в нижней строке как статус. Когда места мало (минимум ноды + метки), ширину отдаёт подпись ряда «Библиотека:» (уходит в многоточие), а подписи кнопок не режутся никогда.
- Клик по книге = выбрать + панель: название, категория, полный текст, формуляр, 📋 Копировать, ✏️/💾 правка, 💾 **Экспортировать** (v1.33: запись на диск — системный выбор папки, Chrome/Edge; с обложкой — подпапка `<название>/` с `.md` и превью, без обложки — только `.md` в выбранную папку), 📥 Воркфлоу, 🌐 **В HTML** (v1.46 — галерея записи, §41). В режиме правки появляются **✖ Отмена** (выйти без сохранения; спросит, если правки есть) и **🖼 Заменить превью** (тоже с подтверждением). Кнопки `💾` не боятся двойного клика — второй клик игнорируется, пока идёт запись.
- Массовый экспорт (v1.34): **одна умная кнопка «📤 Экспорт»** (с v1.48 — в строке «Библиотека:» под ручным вводом, не в шапке проводника): при активных метках (Ctrl/Shift) экспортирует отмеченные записи и категории, без меток — текущую выбранную категорию (и «Всё»/«Избранное»/«Без категории» — вся база). Пишет на диск зеркало иерархии: папка категории → `.md` + обложка рядом, подкатегории — вложенными папками. Идёт с резиновым прогресс-баром в нижней строке (скрывая подсказку до/после экспорта). Chrome/Edge (File System Access API). Отдельных 📤 на строках дерева и в bulk-баре НЕТ (переработано).
- В списке узлов `📎 Текст в базу` не показываются узлы в режимах **mute и bypass** — они всё равно не исполнились бы (с v1.27).
- Ctrl/Shift+клик по карточкам и категориям — мультивыделение и массовое удаление (кнопки массового экспорта/удаления в нижней строке НЕТ — поведение определяется умной кнопкой в шапке проводника: метки → отмеченное, без меток → категория/вся база, §39; Esc/пустое место — снять выделение).
- Кнопки книги: 📌 Закреп (только в папке — книга висит вверху папки), ★ Избранное, ✏️ Переименовать, 🗑 Удалить.
- Карточка несёт воркфлоу: тяни её на канвас (или 📥 в панели) — откроется сохранённый граф, как из PNG. Сам файл превью тоже с workflow внутри — открывается и из проводника.

## Хранение

`ComfyUI/user/prompt_library/library.json` (`{entries, folders}`) + `previews/{id}.png`
(PNG 512px со встроенным чанком `workflow`, legacy `{id}.jpg` мигрирует сам) — общая
база для всех воркфлоу, переживает обновления. Старый формат (список, `category`) и
битые записи мигрируют автоматически.

Префикс `__` в именах категорий зарезервирован под служебные ветки дерева
(`__all` — «Всё», `__fav` — «Избранное», `__root` — «Без категории»), поэтому такие
имена не создаются.

## Установка

Скопировать папку `Prompt_Library` в `ComfyUI/custom_nodes/` и перезапустить ComfyUI.
