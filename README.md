# Prompt Library

Библиотека промптов для ComfyUI как настоящая библиотека: книги (название + текст + обложка-превью) на полках (папки/подпапки), поиск по названию и тексту, порядок полки, ★ избранное, дата выдачи. Автосохранение с превью и выдача нужного промпта в рабочий процесс.

Продолжение серии Prompt Keeper (тот хранит последний промпт, этот — всю базу).

## Схема

```text
LLM / Keeper → source → [Prompt Library] → prompt_out → CLIP Encode
VAE Decode IMAGE → image ┘ (превью, опционально)
```

> Нода с IMAGE-проводом от даунстрима не может одновременно выдавать текст в апстрим (цикл).
> Рабочая схема — две копии с общей базой: «выдача» до CLIP (без IMAGE) + «сейвер» после
> картинки (выход никуда, пассивный отводок).

## Режимы

- **Сквозной** (`Выдавать выбранный = выкл`): входящий промпт идёт на выход как есть + сохраняется в базу (если `Автосохранение = вкл`).
- **Выдача** (`Выдавать выбранный = вкл`): на выход идёт текст записи, выбранной кликом в списке (фиксируется дата выдачи).

## Сохранение — три пути

- Автоматически при Queue (`Автосохранение = вкл`, дедупликация по тексту+папке).
- Кнопка **💾 Сохранить промпт** — текст из окна + папка из виджета, без запуска Queue.
- Папка сохранения: виджет `Папка`, путь `Фото/Портреты` (`/` = подпапка), пусто = корень.

## UI ноды

- Вход `source` (ANY) — провод от LLM/Keeper; окно `Промпт` показывает входящий текст (высота = виджет `Высота окна`).
- Поиск по названию/тексту/папке + порядок полки + вид как в проводнике (🖼 Крупные / 🎞 Средние / 📋 Список).
- Дерево полок: 📚 Всё, ★ Избранное, 📥 Без полки + папки (создать `+ Полка`, ✏️ переименовать, 🗑 удалить — книги переезжают в корень, не теряются).
- Клик по книге = выбрать + панель: название, полка, полный текст, формуляр, 📋 Копировать, ✏️/💾 редактирование.

## Хранение

`ComfyUI/user/prompt_library/library.json` (`{entries, folders}`) + `previews/{id}.jpg` — общая база для всех воркфлоу, переживает обновления. Старый формат (список, `category`) мигрирует автоматически.

## Установка

Скопировать папку `Prompt_Library` в `ComfyUI/custom_nodes/` и перезапустить ComfyUI.
