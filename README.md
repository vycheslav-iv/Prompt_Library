# Prompt Library

Библиотека промптов для ComfyUI как настоящая библиотека: книги (название + текст + обложка-превью) по категориям (дерево, подкатегории), поиск по названию и тексту, порядок категории, ★ избранное, дата выдачи. Автосохранение с превью и выдача нужного промпта в рабочий процесс.

Продолжение серии Prompt Keeper (тот хранит последний промпт, этот — всю базу).

## Схема

```text
LLM / Keeper → source ──┐
                        ▼
                 [Prompt Library] → prompt_out → CLIP Encode
VAE Decode IMAGE → image ┘ (превью, опционально)
```
Ручной ввод — в окно; провод — в подписанный вход `source` («Промт (вход)»).

> Нода с IMAGE-проводом от даунстрима не может одновременно выдавать текст в апстрим (цикл).
> Рабочая схема — две копии с общей базой: «выдача» до CLIP (без IMAGE) + «сейвер» после
> картинки (выход никуда, пассивный отводок).

## Режимы (переключатель `Режим`)

- **📥 Запись**: входящий промпт идёт на выход как есть + сохраняется в базу (дедупликация по тексту — в любой категории: тот же промпт в другой папке второй раз не сохраняется, а показывается, где лежит оригинал).
- **📤 Выдача**: на выход идёт текст записи, выбранной кликом в списке (режим переключается вручную, клик его не меняет; фиксируется дата выдачи).

## Сохранение

- Автоматически при Queue (режим 📥 Запись, дедупликация по тексту — любая категория).
- Кнопка **💾 Сохранить промпт** — текст из окна в открытую в дереве категорию, без запуска Queue
  (можно приложить превью с диска — `📷 Прикрепить превью`, даунскейл до 512px в браузере).
- Обе ноды Library в графе (и вкладки) обновляют список сами: любое изменение
  (сохранение, удаление карточек/папок, ★, переименование, перетаскивание) — ноды
  одного графа синхронны сразу, а между вкладками сигнал идёт через WebSocket
  `prompt_library/refresh` → перечитывается база (`GET /prompt_library/list`).
- Куда сохраняет: на какой категории стоит дерево, туда и пишет («Всё» = корень). Отдельного поля нет.

## UI ноды

- Провод от LLM/Keeper — во вход `source`; окно показывает входящий текст после выполнения.
- Поиск по названию/тексту/категории + порядок категории + вид как в проводнике (🖼 Крупные / 🎞 Средние / 📋 Список, запоминается) + фильтр типа (Всё / 📷 Фото / 🎬 Видео — метка ставится сама по проводу превью).
- Кнопка `➕ Добавить промпт` — ручной ввод в текущую категорию, без запуска Queue.
- Дерево категорий: 📚 Всё, ★ Избранное, 📥 Без категории + категории (создать `+ Категория`, ✏️ переименовать, 🗑 удалить — книги переезжают в корень, не теряются; перетаскивание мышью).
- Клик по книге = выбрать + панель: название, категория, полный текст, формуляр, 📋 Копировать, ✏️/💾 редактирование, 📥 Воркфлоу.
- Ctrl/Shift+клик по карточкам и категориям — мультивыделение и массовое удаление (кнопки `🗑 Удалить` / `✖` появляются в нижней строке ноды вместо подсказки, Esc/пустое место — снять).
- Карточка несёт воркфлоу: тяни её на канвас (или 📥 в панели) — откроется сохранённый граф, как из PNG. Сам файл превью тоже с workflow внутри — открывается и из проводника.

## Хранение

`ComfyUI/user/prompt_library/library.json` (`{entries, folders}`) + `previews/{id}.png`
(PNG 512px со встроенным чанком `workflow`, legacy `{id}.jpg` мигрирует сам) — общая
база для всех воркфлоу, переживает обновления. Старый формат (список, `category`) и
битые записи мигрируют автоматически.

Префикс `__` в именах категорий зарезервирован под служебные ветки дерева
(`__all` — «Всё», `__fav` — «Избранное», `__root` — «Без категории»), поэтому такие
имена не создаются.

## Установка

Скопировать папку `Prompt_Library` в `ComfyUI/custom_nodes/` и перезапустить ComfyUI.
