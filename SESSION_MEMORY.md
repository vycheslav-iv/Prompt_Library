## 1. Что делали в этой сессии (кратко)

- **v1.60: обложка записи — итог прогона, а не вход.** По отчёту пользователя
  (img2img, Qwen-Image): в базу писалась обложка-превью ЗАГРУЖЕННОГО кадра,
  а не итог генерации. Причина: в img2img-воркфлоу первым с картинкой
  исполняется preview загруженного кадра (`type: "temp"`), а итоговый
  `SavePreviewImage` (`type: "output"`) приходит позже — старый гейт
  `!has(pid)` фиксировал первую картинку навсегда и поздний вывод
  игнорировался.
- **Фикс (JS, `plExecuted`, images-ветка):** в запас `st.runImages` идёт самая
  поздняя картинка с приоритетом `output` над temp-превью:
  `replace = !prev || shot.type === "output" || prev.type !== "output"`.
  Превью НЕ затирает уже сохранённый output; поздний output затирает превью.
  `rec.image` (запись в ожидании, `savePickup`) синхронизируется тем же
  правилом. Кап `PL_PENDING_LIMIT` — только на `freshKey` (первый файл прогона).
- **Красная проверка ДО фикса**: новая фаза смоука «итог (output) побеждает
  ранний temp-превью кадра» дала 2 `ASSERT FAIL` на старом коде; после фикса —
  зелёная. Итог: смоук **119 фаз**, py 430/430, статический аудит чист,
  `check.py Prompt_Library --strict` — ЗЕЛЁНЫЙ (4/4).
- **SPEC + память + коммит/пуш** (этот файл). Коммит pумя v1.60 (сделан).
- Дизайн-вопрос «опция выбора ноды для превью (как для текста)» — после
  разбора кода решено **оставить как есть**: детерминированный источник уже
  есть — вход `image` ноды по проводу; зеркальную дропдаун-опцию не делали.
- Синк в рабочую копию выполнен (5 файлов) — **ComfyUI ждёт перезапуска**.

## 3. Проблемы, которые встречались (и как решали)

- **Первая исполнившаяся с картинкой нода = temp-превью загруженного кадра, а
  итог приходит позже** (img2img). Старый `!has(pid)` навсегда фиксировал вход.
  Решение — правило replace v1.60 (output сильнее превью; превью не затирает
  сейв). Эвристика бессильна в графах с несколькими сейверами — там
  детерминированный источник = провод во вход `image` (или ручная смена
  обложки в карточке).
- **Предложение в скил `comfyui-deferred-capture`** (ловушка «первый исполнившийся
  с картинкой — превью входа») — вопрос задан, ответа не было; спросить снова.

## 4. Что важно не сломать при продолжении работы

- **НЕ возвращать гейт «первая картинка навсегда»** (`!has(pid)` без
  `replace`): поздний output обязан перезатирать превью входа.
- Правило приоритета: `output` > temp-превью, но temp-превью НЕ перезаписывает
  уже сохранённый output (в прогоне один сейв — превью отбрасывается).
- `savePickup`/`plDone`/`pickup` (текст) не трогать — фикс v1.60 их не меняет.
- Точная строка `PL_JS_VERSION` в смоуке/check.json/аудите НЕ пиннится.
- `check.py --strict` ПЕРЕД «готово» (правило проекта). Python-правки — после
  перезапуска ComfyUI, JS — Ctrl+F5.
- Память/коммиты — только в папке проекта `Prompt_Library` (отдельный git).
