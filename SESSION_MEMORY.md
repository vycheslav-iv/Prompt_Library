## 1. Что делали в этой сессии (кратко)

- **HTML-галерея доведена до правды**: «Параметры генерации» теперь показывают
  только то, чем реально генерили (v1.46 → v1.53). Три дефекта закрыты по
  замечаниям пользователя, каждый — тестом, который падал на старом коде:
  1. **v1.47–v1.49** — в графах нет штатных `CheckpointLoaderSimple`/`LoraLoader`:
     модель в `diffusion_models` через САБГРАФ со свитчем, LoRA — слоты rgthree.
     Переключатели разрешаются, обход сужен до входов-данных генерации.
  2. **v1.50–v1.51** — ПРОВОД важнее виджета (шаги/разрешение идут проводом;
     в `KSampler` остаётся мёртвое `8`), позиционная подстановка перекрытий
     сабграфа затирала имя LoRA её же силой; фолбэк «по всему графу» подмешивал
     ВЫКЛЮЧЕННУЮ ветку → лишняя turbo-LoRA. Цепочка к сэмплеру авторитетна.
  3. **v1.52–v1.53** — массовые действия (`🗑 Удалить`, `✖`) переехали из нижней
     строки в ряд «Библиотека:» справа; внизу остался только счётчик (статус).
- Попутно поймано **враньё прибора**: детектор обрезки в живой пробе смотрел
  `scrollWidth > clientWidth`, а у кнопок UA-стиль клипит содержимое → ложное
  «зелёное». Прибор переписан (дефект = уменьшение ширины ребёнка против
  свободного состояния, «жертвенный» — по `flex-shrink`).
- **Оформлены скилы**: новый `comfyui-workflow-graph-parsing` (+ строки в `AGENTS.md` §3),
  дополнены `comfyui-negative-result-audit` (ложное ЗЕЛЁНОЕ) и
  `comfyui-dom-widget-sizing` (механика ряда). Все три — в `.agents`/`.kilo`/`.opencode`.
- Закоммичено и запушено: `5e3809c` (код + тесты + спека + README), синк выполнен.

## 3. Проблемы, которые встречались (и как решали)

- **Галерея писала все модели воркфлоу** → разрешение переключателей + обход только
  по входам-данным генерации, сужение до активной ветки (§43).
- **`steps = 8` вместо 12/10, turbo-LoRA исчезала** → провод важнее виджета;
  перекрытия сабграфа по имени; сила LoRA из `strength_model` (§44).
- **Лишняя LoRA при ветке без лоры** → цепочка авторитетнее фолбэка; пустой список
  LoRA = «лоры не было» (§45). Перегиб (жёсткий гейт убил плоские графы) поймали тесты.
- **TDZ при переносе кнопки** → `appendChild` делать в блоке создания `bulkDel`, а не там,
  где создан `exportRow` (иначе роняет `onNodeCreated`).
- **Ложное «зелёное» прибора** → см. §1; правило в скил `comfyui-negative-result-audit`.

## 4. Что важно не сломать при продолжении работы

- **`_gen_meta`: цепочка авторитетна.** Не возвращать безусловный `setdefault` из
  `_generic_meta` — вернётся лишняя LoRA из выключенной ветки.
- **Перекрытия сабграфа — только по имени виджета** (`widgets_values_named`);
  позиция — фолбэк для старых снимков. Позиционно у `LoraLoaderModelOnly` сила
  затирает ИМЯ.
- **`hintRow` — статус, `exportRow` — действия.** Кнопки в ряду получают
  `flex-shrink:0`; сжимается только подпись ряда (`flex:0 1 auto` + эллипсис).
  `BASE_H = 652` не читается из DOM.
- **Высоты — константы**, ничего не меряется через `scrollHeight`/`offsetHeight`.
- Правки серверные (Python) видны только после **перезапуска ComfyUI**; JS — Ctrl+F5.
- Спека и «текущее состояние» (§17) держать в актуальном виде: расхождение с кодом
  ловится глазами, а не проверкой.
- Проба `_probe_live_dom.py` требует **питон ComfyUI** (`python_embeded`) — на системном
  нет `websockets`.
