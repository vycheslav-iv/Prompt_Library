## 1. Что делали в этой сессии (кратко)

Новая задача от пользователя: в режиме **📤 Выдача** база намеренно не
пополняется — нужен путь «сгенерировал → понравилось → забрал в базу».
Сделана кнопка **💾 Сохранить промпт** (иконка дискетки) над кнопкой
«Протестировать / ➕ Добавить промпт»: она придерживает последний прогон
(текст + картинка/видео + граф) и по нажатию создаёт запись с превью.
Видна **только в «Выдаче»** (решение пользователя); в «Запись» и
«Выдача + запись» её нет — там база пишется сама.

Цвет кнопки выбирался 4 итерациями по решению пользователя: зелёный →
янтарный → серый `#484848` (RGB 72,72,72) → **финал: цвета выделенной
карточки** `#2a5a91` + рамка `#4a9eff`, текст `#dfe8ff`.

Закоммичено и запушено: `bd0402d` (origin/master). Живая проверка
пользователем пройдена («работает, устраивает»).

## 3. Проблемы, которые встречались (и как решали)

- **Массовая перекраска чужих элементов (моя ошибка).** При откате мутации
  цвета скрипт заменил подстроку `background:#2a2a2a;color:#ddd` **во всём
  файле** → 12 чужих элементов стали серыми (поиск, сортировки, вид, тип,
  «Протестировать», «💾 Сохранить промпт» окна, «Прикрепить превью»,
  «Снять метки», селект подхвата, поле категории, кнопки панели книги).
  Пользователь увидел это на скриншоте. Исправлено: все 12 возвращены,
  серым осталась только новая кнопка. **Урок: правку делать точечной
  заменой с проверкой числа совпадений, а не «заменить все» + откат.**
- **Детекторы старых тестов сломались новым контрактом (правлен ТЕСТ, §2.3):**
  - поиск кнопки ручного сохранения находил НОВУЮ кнопку (подписи одинаковые)
    → исключить `st.saveRunBtn`;
  - «8 детей root» → 9 (новая строка), `children[7]` → `children[8]`;
  - проверка «на дубликат превью не отправляется» была **слепой** (без
    картинки `attachPreview` не вызывался бы) → в фазу добавлен файл прогона.
- **Красное ДО правки:** Python `FAIL: 1` («граф прогона сохранён файлом»),
  смоук — 5 фаз v1.76 (нет `saveRunRow`/`saveRunBtn`/`lastRun`/`saveLastRun`).
- **Мутации (все красные, восстановление зелёное):** функциональные 6/6
  (придержание 11 FAIL; без `workflow` 1; строка всегда `flex` 2; сервер без
  `_attach_workflow` `FAIL: 1`; дубликат в ветку сохранения 2; приоритет
  текста подхват/вход 2) + цветовые 3/3 (возврат к прежнему цвету → 1 FAIL;
  перекраска чужого элемента → охранитель красный).

## 4. Что важно не сломать при продолжении работы

- **Охранитель цвета** (смоук, фаза v1.76.4): в DOM ноды ровно один элемент
  с `background:#2a5a91` — новая кнопка. Любая перекраска чужих элементов
  этим цветом ловится. Не расширять цвет на другие контролы молча.
- Кнопка появляется только в «Выдаче»; `st.syncSaveRun()` — единственная
  точка видимости (вызывается из callback режима, `onConfigure`, rAF).
- `st.lastRun` заполняется только если: режим «Выдача», текст непустой,
  сервер не сохранил запись сам (`rec`/`saved_id` пуст).
- Дубликат → превью не отправляется, подсказка называет папку оригинала;
  повторное нажатие после сохранения не шлёт запросов.
- Скилы живут в трёх зеркалах (`.opencode/`, `.kilo/`, `.agents/`) — правки
  только в `.opencode`, затем `cp` в два других; `check.py` сверяет побайтово.
- Значения combo — протокол (`getOptionLabel`); Nodes 2.0 — `window.comfyAPI.app`.
